# 📸 Project Screenshots

This folder contains screenshots documenting the development, analysis, and visualization stages of the **Retail Sales & Customer Performance Analysis** project.

The screenshots demonstrate the complete workflow, from data exploration and cleaning to SQL analysis and interactive Power BI dashboards.

## 1. Python Data Analysis

Python was used to explore, clean, transform, and analyze the retail sales dataset.

Key activities include:

* Dataset loading and initial exploration
* Data cleaning and data validation
* Handling missing values and duplicate records
* Feature engineering and creation of new analytical columns
* Sales and profit analysis
* Category and regional performance analysis
* Customer purchasing behavior analysis
* Data visualization and business insights

## 2. SQL Analysis

SQL was used to query the transformed dataset and extract meaningful business insights.

Key activities include:

* Total sales and total profit calculations
* Total orders and customer analysis
* Sales and profit analysis by category
* Regional sales analysis
* Top 10 customers by sales
* Aggregation using `SUM()`, `AVG()`, and `COUNT()`
* Filtering, grouping, sorting, and ranking records

## 3. Power BI Dashboards

Power BI was used to create interactive dashboards to analyze sales, customers, products, and business performance.

### Dashboard 1: Retail Sales Analysis

This dashboard focuses on overall sales and profitability.

Key features:

* Sales and profit KPIs
* Sales performance by category and region
* Monthly and yearly sales trends
* Profit margin analysis
* Product performance insights
* Interactive slicers for Year, Month, Region, and Category
